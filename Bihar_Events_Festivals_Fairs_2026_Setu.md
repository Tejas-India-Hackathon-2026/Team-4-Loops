# Bihar Events, Festivals & Fairs Calendar — 2026

> **Purpose:** Reference data for the **Setu Bihar tourism ecosystem**. This document organizes Bihar's major tourism events, festivals, fairs and cultural/religious celebrations month-wise.

## Important Accuracy Note

The event dates below are based primarily on the **Bihar Tourism 2026 event calendar**. Some religious festivals follow lunar/Hindu calendars and therefore change dates every year. Such festivals should be stored in Setu with year-specific dates rather than permanently hard-coded dates.

Official Bihar Tourism events calendar:
- https://tourism.bihar.gov.in/en/events

## Shravani Mela

Shravani Mela is one of Bihar's major pilgrimage events. Devotees traditionally collect Ganga water at Sultanganj and undertake the Kanwar pilgrimage.

For Setu, this should be treated as a major tourism event with dedicated information about:
- Pilgrimage route
- Accommodation
- Food
- Transport
- Medical/emergency facilities
- Local vendors
- Crowd information
- Important stops

# Setu — Recommended Event Classification

Instead of storing every event as simply a "festival", Setu should classify events into categories.

| Category | Examples |
|---|---|
| Religious | Chhath, Shravani Mela, Pitrapaksha |
| Cultural | Rajgir Mahotsav, Mithila Mahotsav |
| Fair / Mela | Sonpur Mela, Makar Mela |
| Heritage | Vikramshila Mahotsav, Rohtas Garh Kila Mahotsav, Sher Shah Mahotsav |
| Music / Arts | Buddha Mahotsav, Sufi Mahotsav |
| Local / Regional | Koshi Mahotsav, Munger Mahotsav |

```text
├── transport_information

├── nearby_restaurants
├── nearby_attractions
├── local_vendors
├── local_products
├── accessibility_information
├── emergency_information
└── last_verified
```

## Why `year` and `last_verified` are important

Festival dates can change every year. Therefore, Setu should not assume that an event occurring on a particular Gregorian date in 2026 will occur on the same date in 2027.

Example:

```json
{
  "event_name": "Pitrapaksha",
  "year": 2026,
  "start_date": "2026-09-26",
  "end_date": "2026-10-10",
  "recurring_event": true,
  "last_verified": "2026-08-20"
}
```

For the next year, the dates should be independently verified and a new yearly event record created.

# Important Product Decision for Setu

The calendar should **not be treated as a static page**.

It should become a live tourism discovery system:

```text
                    EVENT
                      │
        ┌─────────────┼─────────────┐
        ▼             ▼             ▼
     TOURIST        VENDOR         HOTEL
        │             │             │
    Discover       Sell at       Prepare for
    & Plan         event         demand
        │             │             │
        └─────────────┼─────────────┘
                      ▼
                  SETU ECOSYSTEM
```

This connects the three sides of Setu:

**Tourists** → discover events and plan trips  
**Local vendors** → discover upcoming demand and promote products/services  
**Hotels/restaurants** → prepare for seasonal/event-based tourist traffic

This makes the event calendar a functional part of the Setu ecosystem rather than just an information page.
